# Future Technology — موقع متكامل (Backend + Frontend)

موقع "فيوتشر للتقنية" الكامل: واجهة عامة ثنائية اللغة (عربي/إنجليزي)، نظام تسجيل دخول وحسابات مستخدمين، إعادة تعيين كلمة المرور، ولوحة تحكم للمسؤول تقدر تعدّل منها الهوية والشعار والألوان وكل محتوى الموقع بدون لمس الكود.

---

## 1. المتطلبات

- [Node.js](https://nodejs.org) نسخة 18 أو أحدث (يشمل npm)

تأكد إنه مثبت عندك بتشغيل:
```bash
node -v
npm -v
```

---

## 2. التثبيت والتشغيل (محلياً)

```bash
# 1) فك ضغط المشروع وادخل المجلد
cd future-technology-website

# 2) ثبّت المكتبات
npm install

# 3) انسخ ملف الإعدادات وعدّله
cp .env.example .env
```

افتح ملف `.env` وعدّل على الأقل:
- `JWT_SECRET` — سلسلة عشوائية طويلة وسرّية (لا تشاركها مع أحد)
- `ADMIN_EMAIL` و `ADMIN_PASSWORD` — بيانات حساب المسؤول الافتراضي (يُنشأ تلقائياً أول تشغيل)

```bash
# 4) شغّل السيرفر
npm start
```

بعدها افتح المتصفح على: **http://localhost:3000**

- الموقع العام: `http://localhost:3000`
- تسجيل الدخول: `http://localhost:3000/login.html`
- لوحة التحكم (للمسؤول فقط): `http://localhost:3000/admin/dashboard.html`

سجّل دخولك بحساب المسؤول اللي حطيته بـ `.env` (`ADMIN_EMAIL` / `ADMIN_PASSWORD`)، وبتدخل تلقائياً للوحة التحكم.

> ⚠️ **مهم:** غيّر كلمة مرور المسؤول من أول ما تسجّل دخول (عن طريق "نسيت كلمة المرور" أو بتعديل `ADMIN_PASSWORD` بالـ `.env` وحذف قاعدة البيانات `data/database.sqlite` لإعادة الإنشاء).

---

## 3. لوحة التحكم — وش تقدر تعدّل

من `/admin/dashboard.html` (بعد تسجيل الدخول كمسؤول):

| القسم | وش يحتوي |
|---|---|
| **الهوية والشعار** | رفع/تغيير الشعار، اسم العلامة التجارية بالعربي والإنجليزي |
| **الألوان** | الألوان الخمسة الأساسية للموقع (تنعكس فوراً على كامل الموقع) |
| **الرئيسية (Hero)** | عنوان ووصف الصفحة الرئيسية والإحصائيات الثلاث |
| **من نحن** | عنوان القسم، الفقرتين، وخطوات العمل (قابلة للإضافة والحذف) |
| **رؤيتنا** | عنوان ونص قسم الرؤية |
| **الخدمات** | حتى 7 خدمات، كل وحدة برقم/وسم وعنوان ووصف بالعربي والإنجليزي |
| **تواصل معنا** | عنوان ووصف القسم، البريد، العنوان، ورقم واتساب مع رسالة البدء |
| **المستخدمون** | قائمة كل من سجّل حساب بالموقع |

أي تعديل يحتاج ضغط زر **"حفظ التغييرات"** بالأسفل عشان ينحفظ ويظهر على الموقع مباشرة (بدون إعادة تشغيل السيرفر).

## 4. تسجيل الدخول وكلمة المرور

- **إنشاء حساب:** أي زائر يقدر يسوي حساب من `/register.html` (يصير دوره `user`).
- **تسجيل الدخول:** من `/login.html`.
- **نسيت كلمة المرور:** من `/forgot-password.html` — يرسل رابط إعادة تعيين صالح لمدة ساعة.
  - إذا ما ضبطت إعدادات SMTP بالـ `.env`، الرابط بيُطبع فقط في الـ terminal (console) بدل ما يُرسل بالإيميل — مفيد للتجربة المحلية.
  - لتفعيل الإرسال الفعلي بالإيميل، عبّي `SMTP_HOST` و `SMTP_USER` و `SMTP_PASS` وغيرها بالـ `.env` (تقدر تستخدم Gmail App Password، SendGrid، Mailgun، أو أي مزوّد SMTP).
- **ترقية مستخدم لمسؤول:** حالياً عن طريق قاعدة البيانات مباشرة أو بإضافة استدعاء لـ `PATCH /api/users/:id/role` (الراوت جاهز بالباك-إند).

```
    ├── admin/dashboard.html    لوحة التحكم

    ├── js/auth-pages.js
    ├── js/admin.js
    └── uploads/                ملفات الشعار المرفوعة
```

## 6. نقاط الـ API (Endpoints)

| Method | المسار | الوصف | صلاحية |
|---|---|---|---|
| POST | `/api/auth/register` | إنشاء حساب جديد | عام |
| POST | `/api/auth/login` | تسجيل الدخول | عام |
| GET | `/api/auth/me` | بيانات المستخدم الحالي | مسجّل دخول |
| POST | `/api/auth/forgot-password` | طلب رابط إعادة تعيين | عام |
| POST | `/api/auth/reset-password` | تنفيذ إعادة التعيين | عام (برمز صالح) |
| GET | `/api/content` | جلب محتوى الموقع كامل | عام |
| PUT | `/api/content` | تعديل محتوى الموقع | مسؤول فقط |
| POST | `/api/content/logo` | رفع شعار جديد | مسؤول فقط |
| GET | `/api/users` | قائمة كل المستخدمين | مسؤول فقط |
| PATCH | `/api/users/:id/role` | تغيير صلاحية مستخدم | مسؤول فقط |

كل الطلبات المحمية تحتاج ترويسة:
```
Authorization: Bearer <token>
```

## 7. النشر على استضافة (Deployment)

المشروع Node.js عادي يشتغل على أي استضافة تدعم Node، مثل:
- **Render / Railway / Fly.io** — ارفع المجلد، اضبط متغيرات البيئة من لوحة الاستضافة، وشغّل `npm start`.
- **VPS (Ubuntu مثلاً)** — ثبّت Node، ارفع الملفات، شغّل بـ [PM2](https://pm2.keymetrics.io/) لإبقاء السيرفر شغّال:
  ```bash
  npm install -g pm2
  pm2 start server.js --name future-technology
  ```
  وضع السيرفر خلف Nginx كـ reverse proxy مع شهادة SSL (Let's Encrypt).

**ملاحظات مهمة قبل النشر:**
- غيّر `JWT_SECRET` لقيمة قوية وسرّية.
- غيّر بيانات المسؤول الافتراضية فوراً.
- فعّل SMTP حقيقي لإرسال روابط إعادة التعيين.
- اعمل نسخة احتياطية دورية لملف `data/database.sqlite`.

## 8. تخصيص إضافي

- كل الألوان مبنية على CSS variables (`--navy-950`, `--teal`, `--gold`...) — تعديلها من لوحة التحكم يطبّق فوراً على كل الموقع.
- المحتوى بالكامل (نصوص، خدمات، تواصل) محفوظ كـ JSON بجدول `site_content` — تقدر تعدّله مباشرة بقاعدة البيانات لو احتجت لتغييرات متقدمة خارج لوحة التحكم.
